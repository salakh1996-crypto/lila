# О WayChess

WayChess — бесплатный шахматный сайт, который работает в России без VPN.

## Что здесь есть

- Игра онлайн с любым контролем времени: от пули до заочных партий.
- Рейтинг по системе Glicko-2.
- Турниры: арены и швейцарская система.
- Шахматные задачи и Puzzle Storm.
- Анализ партий движком Stockfish.
- Изучение дебютов и совместная доска для занятий с тренером.
- Командные турниры, клубы и классы для шахматных школ.

## Откуда WayChess

WayChess основан на открытом коде [Lichess](https://lichess.org), одного из
крупнейших шахматных сайтов в мире, и распространяется по той же лицензии
GNU AGPL. WayChess — независимый проект и не связан с Lichess.
[Исходный код WayChess](/source) открыт.
